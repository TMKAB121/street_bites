# Writing-style samples

Drop `.md` posts in this folder — the content-writer agent mimics whatever
is here. The three starters were lifted from the seeded demo posts
(`database/seeders/NewsSeeder.php`); **replace them with your own writing**
as soon as you have real posts, and add new ones any time your voice evolves.

Each sample uses the same layout the agent's deliverable (`post.md`) uses:
frontmatter with `title` (plus `event_date` / `event_location` for events),
then the Markdown body. The body is what teaches style; the frontmatter shows
how the fields get used.
